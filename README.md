# Natirut Duangpak — 3D Resume

A scroll-driven, cinematic resume. Six WebGL scenes, starring a sci-fi android helmet modelled in Blender. As you scroll, the camera **dives** into a focal point in each scene (the helmet's lens, the neural core, the processor), and the next scene blooms through a halftone-dot dissolve. The look borrows from editorial print: halftone clouds, engraved line work, serif type and hairline guides, with HDR bloom on the neon.

The helmet is generated by a Blender Python script ([tools/blender/build_helmet.py](tools/blender/build_helmet.py)). The other models are built in code from Three.js primitives.

## How it works

- **Director** ([components/three/Scene.tsx](components/three/Scene.tsx)): each chapter lives in its own `THREE.Scene` via `createPortal`. Every frame, only the current chapter (and the next one, during a dive) is rendered into multisampled half-float render targets.
- **Compositor** ([components/three/compositor.ts](components/three/compositor.ts)): a full-screen shader that zooms scene A toward its focus with radial blur and chromatic fringe, grows scene B out of its anchor, and swaps them through a rotated halftone screen. The result stays in linear HDR for the post chain.
- **Scroll mapping** ([components/ui/SmoothScroll.tsx](components/ui/SmoothScroll.tsx)): Lenis smooth scrolling plus keyframes taken from each section's DOM position. That way the camera rests while a section is on screen and dives in the spacers between sections.
- **Camera rig** ([components/three/stage.ts](components/three/stage.ts)): arrive, rest and dive easing, pointer parallax, and an automatic pull-back on portrait screens.
- **Blueprint shader** ([components/three/models/Blueprint.tsx](components/three/models/Blueprint.tsx)): re-renders any model as contour lines, cross-hatching, silhouette rims and edge lines, revealed by a clipping plane.
- **Post-processing** ([components/three/postfx.ts](components/three/postfx.ts)): HDR dual-Kawase bloom, filmic highlight roll-off, fine grain and vignette.
- **Helmet effects** ([components/three/models/Helmet.tsx](components/three/models/Helmet.tsx)): glTF materials patched with a materialise cut, a scan wave and a hologram neck cut; the neon powers on with a flicker.
- **Performance**: 4× MSAA and up to 2× pixel ratio by default. If frames drop, drei `PerformanceMonitor` first swaps MSAA for FXAA, then steps the pixel ratio down. Inactive chapters skip their animation work.

## Rebuilding the helmet

Install [Blender](https://www.blender.org) 4.2+ and run:

```bash
blender --background --factory-startup --python tools/blender/build_helmet.py -- public/models/helmet.glb tools/blender/preview/helmet path/to/studio.hdr
```

The last two arguments are optional (preview renders and their HDRI). The model is exported with Draco compression; the decoder lives in `public/draco/`.

## Run locally

Requires [Node.js 18.18+](https://nodejs.org).

```bash
npm install
npm run dev
```

Open <http://localhost:3000>.

## Editing the content

All resume content lives in [`data/resume.ts`](data/resume.ts). The one-line chapter captions and the "dive" lines are in [`app/page.tsx`](app/page.tsx).
